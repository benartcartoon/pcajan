# Self Improve
Görev sonunda yalnız doğrulanmış dersleri çıkar.
Tek seferlik tesadüfi ayrıntıyı kalıcı kurala dönüştürme.
Tekrarlanan hata için kök neden + önleyici kontrol + doğrulama adımı tanımla.
Mevcut skill'i güncellemeden önce çakışan talimatları kontrol et.
Güvenlik sınırlarını, kullanıcı onayı gerektiren işlemleri veya repo kurallarını gevşetme.
Değişen skill için kısa test senaryosu oluştur ve davranışı doğrula.
